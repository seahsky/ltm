## 1. Proposed title + abstract

### Title (boundary + mechanism lead; audio demoted to subtitle)

**When Does Long-Term Memory Help an Embodied Agent? A Module-Attributed Boundary and Its Instance-Discrimination Cause**
_subtitle:_ with audio as a triggering and gating modality for lifelong anomaly response

> Rationale: the direction-check is explicit that an audio-forward title is indefensible until sound causally changes navigation behaviour, and that the memory architecture is not novel in 2026. Lead with the one finding the crowded memory-nav cluster does *not* provide: **WHEN** embodied LTM stops helping, and **WHY** (the instance bottleneck). Restore an audio-forward title only if the non-LOS sound-on-wins experiment lands (it has not — see §3).

### Abstract (~200 words)

We ask a question the embodied-memory literature usually assumes away: *when* does a lifelong long-term memory (LTM) actually help navigation, and when does it not? On a controlled paired warm/cold revisit harness in Habitat (HM3D), we show a persistent, consolidated, caption-indexed LTM injected into frontier waypoint selection improves warm paired soft-SPL over a memory-off backbone by **+0.23 (n=26 paired warm visits, 90% CI [+0.13, +0.32], one-sided p<0.001)**, with a **clean cold control (S3−S1 = 0.000, n=10)** where no relevant prior sighting exists — a directly observed boundary, not an averaged gain. A module decomposition attributes the effect **entirely to the LTM, not the short-term buffer** (warm paired S2−S1 = −0.009, n=26, n.s.; S3−S2 = +0.238, 90% CI [+0.135, +0.335], p<0.001). We then report a uniformly negative extension result: every *additional* memory head we add — learned importance, learned utility, room-affordance priors, a temporal-recency head, an audio direction-of-arrival re-ranker, and an audio→LTM anomaly write — is inert or redundant, and we trace all six to one directly-measured cause: the caption embedding's instance-discrimination ceiling (within-instance cosine 0.628 vs between-instance-same-category 0.535; the category query collapses the rank gap to 0.047), which a single-goal evaluation never rewards resolving. Audio is demoted to a *triggering/gating* modality: we contribute a zero-shot open-set CLAP anomaly-vs-benign detector (EER 0.00) and a causal onset-gate proving the onset is necessary for warm recall — but we state plainly that **the navigation gain is visual recall, not audio localization**.

_Word count ≈ 205. Framing notes: (i) the headline is the **paired-warm** +0.23, NOT the unpaired overall S3−S1 = +0.166 from the same run — do not conflate. (ii) The +0.115→+0.23 move is a **methodology correction** (shuffle fix), not a new reproduction — see §3. (iii) Audio's two verified roles (open-set detector + causal onset-gate) are stated as applied sub-contributions; the no-op-for-localization is stated as a feature of the boundary story, per the area-chair recommendation._

## 3. Corrected results paragraph

**The headline (corrected, shuffle-fix).** On the wide revisit matrix (6 categories × 2 scenes, n_warm=3) re-run under the episode-ordering shuffle fix, the hierarchical LTM (S3) improves paired warm soft-SPL over memory-off (S1) by **+0.2296 (n=26 paired warm visits, 90% bootstrap CI [+0.1292, +0.3244], one-sided p<0.001)**. Pairing is the renumbering-invariant key `(scene_id, target_category, visit_order)` (`analyze_revisit.py:_visit_key`), so this is a genuine paired delta, not a difference of pooled means. We report the correction transparently: **the archived shuffle-diluted estimate was +0.115 (n=26); fixing the shuffle so warm revisits actually carry a relevant prior sighting raises the fresh re-run to +0.2296 (n=26)**. This is a **cross-run methodology correction, not a paired before/after A/B** — the two values are separate runs (each with its own CI), the fix even changes which episodes count as warm vs cold, and the corrected number is a **single overnight run on one seed, not yet replicated**. The magnitudes happen to stand in a 2.00× ratio (+0.115→+0.2296, absolute +0.1146), so "roughly doubled" is a true statement of the two point estimates — but **there is no statistical test on the difference of deltas**, and we do not claim a significant doubling. The corrected wide value brings the estimate into line with the n=12 chair+bed subset (+0.24) and a single-cell certification (+0.174→+0.338, a smaller different unit, not a second wide run). Honest reproduction count stays at **~2–3 distinct datasets** (n=12 Phase-C, n=26 wide, single-cell cert), not "~12 reproductions."

**Clean cold control.** The same paired machinery restricted to `visit_order==0` (first sighting, no prior same-category memory; `analyze_revisit.py:paired_cold_delta`) gives **cold S3−S1 = 0.000 (n=10)** — every paired cold visit had byte-identical S1 and S3 soft_spl, because memory is provably inert without a prior sighting (S1≡S3 episode-by-episode). This is a *no-difference* control (the predicted boundary), not a noisy near-zero estimate; we quote it as "memory provably inert without a prior sighting." It is the **same-category inert** cold control (audit caveat #4), **distinct** from the separate cross-category lifelong-transfer cold (+0.157) — labelled so a reviewer does not read a contradiction.

**Module decomposition — LTM-specific (confirmed, warm-paired).** The warm-paired S2−S1 / S3−S2 split (same renumbering-invariant pairing as the headline) attributes the entire gain to the LTM, not the STM: **warm S2−S1 = −0.0085 (n=26, 90% CI [−0.026, 0.000], one-sided p=1.000)** — adding the short-term buffer alone changes nothing — and **warm S3−S2 = +0.2381 (n=26, 90% CI [+0.135, +0.335], one-sided p<0.001)** — the full effect lands in consolidation + hierarchical-LTM + rerank (proposal modules 2–4). Three independent lines (cold control = 0.000, STM-only ≈ 0, LTM-specific = +0.238) all attribute the gain to the LTM with a relevant prior. Warm **success@1 m rises 0.154 → 0.423** (the benchmark-comparable 1.0 m ring) and memory fires on **25/26** warm visits (fire-rate 0.962). Binary **SPL@0.1 m S3−S1 = +0.044 (p=0.105, not significant)** — still **localization-bound** (memory recalls a viewing pose, not the 0.1 m point), so we foreground 1.0 m success and demote 0.1 m to a diagnostic. (Note the unpaired overall S3−S1 = +0.166 from the same run is a *different* number — do not quote it as the headline.)

**Audio non-LOS status (honest, underpowered).** In a controlled non-line-of-sight write-ON vs write-OFF A/B on a **single cell** (`wcojb4TFT35`, glass_break:chair; `runs/llA|llB-…-s3`), the audio→LTM write fired (seedW=1, skip_reason=ok) and was recalled at a distance (`n_audio_event_recalled` = 26 and 38), and recall soft-SPL moved in the helpful direction (write-ON 0.213 vs write-OFF 0.144, **B−A = +0.068**) — the **first non-redundant direction** after the line-of-sight A/B was redundant (−0.012). But with **n=2 recall pairs** this is underpowered and inconclusive (pooled 90% bootstrap CI **[0.000, +0.137]**, two-sided **p=0.482**, straddling 0; the lower bound touches 0 because one of the two pairs has a null delta), and the write stamps the **ground-truth source xyz — an oracle/privileged upper bound**, since simulated audio gives only an ITD-weak lateral sign, no range. So this is **directional and mechanism-verified, not evidence that audio writes help.** (Note: the analyzer prints `redundancy_verdict = HELPS` only because +0.068 exceeds its 0.02 tie band; at n=2 that label over-claims — the CI/p line is the honest readout. 2 of the 3 lifelong cells failed to build, so there is no multi-cell pool.) The one-sided revisit p<0.001 and this two-sided p=0.482 are computed differently and must not be compared as if on the same footing.

## 4. Open items (from the direction-check)

Reviewer-blocking gaps the reframe must close before (or explicitly defend at) submission:

- [ ] **GOAT-Bench: run a slice OR write the justification.** Named by axes A/C/D as the single biggest positioning risk ("why not just run GOAT-Bench?"). Either run a GOAT-style multi-goal episode or write the crisp defence of the cross-VISIT revisit regime vs GOAT's within-episode multi-goal regime. Adopt GOAT's 1.0 m SR/SPL conventions; foreground SR@1.0 m (warm 0.33→0.67), demote 0.1 m to a diagnostic.
- [ ] **VLFM external baseline.** The S1/S2/S3 ablation is entirely self-referential. Run a VLFM-style frontier-only baseline under the same harness (closest to S1/S2, cheapest external comparator) so the LTM delta is not measured only against our own backbone. Ideally add one external *memory* comparator (TrajRAG / TopoNav / FOM-Nav style).
- [ ] **Multi-cell powered audio.** The +0.068 non-LOS result is one cell, n=2, with 2 sibling cells failing to build. Build ≥2 scenes with adequate n (and over-fire damping) for a sound-off-vs-sound-on contrast where sound-on wins — the make-or-break experiment that converts audio from dressing to a causal contribution. Until it lands, keep audio framed as trigger/gate and report the oracle write as an explicit upper bound. **Also: a non-oracle (DOA-derived) write** to replace the GT-source upper bound.
- [ ] **rliable-style power accounting.** Report effective independent n (~2–3 datasets), not "~12 reproductions"; add scenes/seeds or a performance profile for the +0.23 / +0.171 headlines; state the leave-best-cell-out softening (audio +0.171→+0.095, p≈0.07) up front. Replicate the corrected +0.2296 wide run at least once (single seed currently).
- [ ] **Query-side instance fix (before any detector).** Per the team's own $0 MIXED verdict and the "Is CLIP the roadblock?" paper ([2404.03539](https://arxiv.org/abs/2404.03539)): try instance-qualified queries / latent re-projection (the cheap, correct first lever) and report it. Cite the DINOv2-ReID-limits work to show a better embedding is real research, not a config flag; OWLv2 is already shown localization-bound, so do not escalate to GroundingDINO/Detic.
- [ ] **Scope-police the title/abstract** for "lifelong cross-environment" (structurally absent — `memory_bridge.py:829` scene filter) and "hierarchical 3-layer" (mid empty, coarse never chosen) over-claims. Keep §7 limitations; make the headline match the measured within-scene fine-layer+rerank reality.
