### Strongest contribution (lead with this)

# Literature by axis

## Axis A — Lifelong / hierarchical / consolidating memory for embodied nav

**SOTA.** As of mid-2026 the field has converged hard on retrieval-augmented and graph-/voxel-structured memory for navigation, and "memory" is no longer a differentiator by itself. The direct lineage to this project is ReMEmbR (Anwar et al., ICRA 2025): a VILA/VLM-captioner + vector-DB of (caption-embedding, position, time) tuples queried by an LLM agent — but ReMEmbR is a long-horizon video-QA system ("where/when did X happen"), NOT a closed-loop navigation policy. A wave of 2025-2026 work turns retrieval-over-past-experience into an action driver: RANa (within-scene image-DB retrieval for ImageNav/ObjectNav, Habitat/Gibson, +15 SPL), TrajRAG (CVPR 2026; hierarchical coarse-to-fine chunking of past trajectories, lifelong accumulation, frontier-hypothesis retrieval on HM3D/MP3D ObjectNav), Embodied-RAG (a hierarchical "semantic forest" at fine→coarse spatial/semantic resolutions, lifelong, kilometer-scale, used for both nav and explanation), and SSMG-Nav (CVPR-era 2026; persistent Semantic Skeleton Memory Graph for lifelong multimodal ObjectNav on GOAT-Bench, 0.341 vs VLFM 0.159 SPL). Hierarchical short-term/long-term memory specifically is the explicit headline of MemoNav (CVPR 2024, STM/LTM/working-memory with a learned forgetting module for image-goal nav) and Mem4Nav (2025, octree+topology dual-memory for urban VLN — but this paper has been WITHDRAWN under an academic-misconduct investigation, so it must be cited with that caveat or avoided). The benchmark that defines "lifelong navigation" is GOAT-Bench (CVPR 2024): 5-10 sequential multimodal goals per episode in unseen HM3D scenes, explicitly designed to test whether scene memory is reused across sub-goals — the exact regime this project's findings say single-goal ObjectNav fails to reward. The importance/recency/relevance scoring this project uses (I=αR+βU+γN) is the Generative Agents (Park et al., 2023) memory-stream formula (score = recency+importance+relevance), now surveyed extensively in 2025-2026 LLM-agent-memory surveys that frame consolidation as "episodic→semantic" compression with forgetting. Bottom line: persistent, hierarchical, consolidating, retrieval-injected memory for navigation is an active and crowded 2025-2026 frontier, not white space.

**How this project relates.** The project sits squarely inside the 2025-2026 'retrieval-over-persistent-experience for navigation' cluster, and overlaps heavily with at least four concurrent systems. SHARED with SOTA: (a) a persistent, within-scene memory queried at run time — identical scope to RANa and to TrajRAG's lifelong accumulation; (b) a hierarchical fine/mid/coarse store — the same multi-resolution idea as Embodied-RAG's 'semantic forest' and the STM/LTM split of MemoNav and (withdrawn) Mem4Nav; (c) memory-INJECTED waypoint reranking of frontier candidates — essentially TrajRAG's 'frontier hypotheses query the memory to guide waypoint selection'; (d) importance/recency consolidation lifted directly from Generative Agents. WHAT IS DIFFERENT / DEFENSIBLE: (1) the honest, heavily-instrumented NEGATIVE results — the project has empirically established, with ablations, that on single-goal ObjectNav the LTM is neutral and that every importance/affordance/recency/audio-DOA head is inert because SBERT/CLIP captions can't discriminate instances; this 'instance-discrimination bottleneck' diagnosis (within-instance cos 0.628 vs between-instance-same-cat 0.535, query collapses gap to 0.047) is a genuinely useful, rarely-published finding the cluster above mostly glosses over. (2) the ICRA-2027 pivot — LTM-grounded ACOUSTIC ANOMALY response (map silently → an FSD50K/ESC-50 anomaly fires from a captioned-goal-co-located source → warm agent recalls the region) is a task framing not occupied by any paper found; the closest, Semantic Audio-Visual Navigation, is heard-sound-source-seeking, not 'persistent-LTM recall triggered by a transient anomaly'. The project's own caveat that audio is currently a code-proven NO-OP for retrieval is the crux: the novelty lives ENTIRELY in making audio load-bearing (the non-LOS audio→LTM write), and that piece is not yet demonstrated.

**Novelty.** Honest verdict: the memory ARCHITECTURE per se (hierarchical fine/mid/coarse consolidating LTM + memory-injected waypoint reranking for navigation) is NOT novel in 2026 — it is independently covered by TrajRAG (hierarchical lifelong retrieval injected into frontier selection), Embodied-RAG (fine→coarse semantic forest, lifelong), MemoNav (STM/LTM + forgetting), and SSMG-Nav (persistent consolidating graph), with the importance scoring taken verbatim from Generative Agents. Presenting the 3-layer LTM as the contribution would be rejected as already-done. The project's own audit caveats make this worse on paper: the '3-layer hierarchy' is in practice fine-layer + rerank (mid empty, coarse never chosen), and cross-env transfer is structurally absent — so the implemented system is LESS than the architectures it would be compared to. WHAT IS GENUINELY NEW / PUBLISHABLE: (a) the ACOUSTIC-ANOMALY→LTM-RECALL task and the audio→LTM write mechanism — IF made load-bearing and shown to beat a vision-only baseline (currently an oracle-source upper bound and a code-proven no-op, so this is the make-or-break); (b) the rigorous negative-result narrative on WHEN lifelong memory helps vs is inert, anchored to a measured instance-discrimination bottleneck — a credible 'lessons/analysis' contribution that most of the cluster above does not provide. Net: as a memory-architecture paper = incremental/already-done; as an acoustic-anomaly-response + honest-analysis paper = potentially novel, but contingent on the audio actually contributing, which the project's own notes say it does not yet.

## Axis B — Audio-goal nav & acoustic anomaly response

**SOTA.** The audio-visual navigation field began with AudioGoal/SoundSpaces (Chen et al., ECCV 2020) — navigate to a continuously-sounding source from binaural audio + vision in Habitat on SUNCG/Matterport3D/Replica — extended by waypoint-setting (Chen et al., NeurIPS 2020), Semantic Audio-Visual Navigation (SAVN, Chen et al., CVPR 2021, where objects make short, semantically-consistent sounds and the agent must localize after the sound STOPS via learned object-sound priors and memory), and moving/unheard sources ("Catch Me If You Hear Me" / Dynamical AVN, 2021-2022). SoundSpaces 2.0 (Chen et al., NeurIPS 2022 D&B) made rendering continuous, geometry-based and arbitrary-sound. SAVN was just ported to continuous environments with a memory-augmented transformer (MAGNet, SAVN-CE, CVPR 2026). On the map/LTM axis, AVLMaps (Huang et al., ISER 2023) already builds a persistent audio-visual-language 3D map and answers audio-cued queries ('go to the table where you heard coughing'), explicitly using sound to disambiguate among multiple same-category instances. Most critically, HomeEmergency (Yan et al., 2025, Amazon Lab126+UMD) defines almost exactly this project's task — prior home exploration to build a spatial/room map, then hear an aperiodic emergency sound (fall/fire), navigate to the source, and verify true-vs-false with a VLM — on ThreeDWorld. CLAP (Wu/Elizalde et al., 2022-2023) is the standard zero-shot audio-language classifier. Acoustic anomaly detection itself is a mature field (DCASE Task 2 first-shot ASD, 2024-2025) but is overwhelmingly machine-condition-monitoring, NOT embodied/navigational.

**How this project relates.** The project sits squarely inside the audio-visual / semantic audio-visual navigation lineage, with an LTM-system twist borrowed from the robot-memory line (ReMEmbR). What it SHARES with SOTA: (a) the SoundSpaces binaural-RIR-on-Habitat rendering substrate (identical to AudioGoal/SoundSpaces 2.0); (b) the SAVN premise that a sound fires, goes silent, and the agent must still reach the region (SAVN CVPR 2021, MAGNet CVPR 2026); (c) the HomeEmergency program of map-a-home-then-respond-to-an-anomaly; (d) the AVLMaps idea of using audio to disambiguate among same-category instances; (e) CLAP as the audio classifier. What is DIFFERENT / potentially distinctive: the memory is an EXPLICIT, persistent, biologically-inspired HIERARCHICAL LTM with a consolidation/importance pipeline (I=alphaR+betaU+gammaN) and memory-injected reranking on a VLM/LLM backbone (ReMEmbR), rather than (i) SAVN/MAGNet's end-to-end RL transducer memory, (ii) HomeEmergency's probabilistic dynamic scene graph + Bayesian fusion, or (iii) AVLMaps' static fused voxel grid. The project also targets HM3D ObjectNav-derived scenes rather than TDW. However — and this is the crux — the team's own honest finding is that in the current eval the anomaly_object equals the target_category equals the goal, so the LTM queries the goal from step 0 and audio is a code-proven NO-OP; the +0.171/+0.24 gains are pure VISUAL revisit recall with audio as dressing. So as currently instantiated the project is closer to 'ObjectNav with a persistent LTM + an audio onset that times the query' than to a genuine acoustic-anomaly-response system, and several of the differentiating LTM heads are reported inert/redundant due to the SBERT instance-discrimination bottleneck.

**Novelty.** Mixed, and the audio framing is the highest-risk part. The COMBINATION 'persistent consolidated hierarchical LTM (ReMEmbR-style retrieval) + acoustic anomaly trigger + recall-the-region' has not been published exactly — no single paper does retrieval-augmented LTM consolidation gated by an acoustic anomaly. BUT each ingredient is taken: HomeEmergency (2025) already does map-home -> hear-anomaly -> navigate-to-source -> verify (the task is essentially solved at the task level, on a different sim and with a non-LTM map); SAVN/MAGNet already do hear-sound -> goes-silent -> memory-augmented recall; AVLMaps already does persistent-audio-visual-map -> audio-disambiguates-instances. So 'LTM-grounded temporal-context anomaly response' is at serious risk of reading as 'AudioGoal/SAVN + HomeEmergency rebranded with a fancier memory module', especially because the team's OWN code shows audio is currently inert for retrieval (sound and goal coincide), which means the headline result demonstrates visual LTM recall, not acoustic-anomaly response. The genuinely novel, defensible pieces are narrow: (1) an explicit consolidation/importance-scored HIERARCHICAL LTM (vs end-to-end or static-map memory) integrated with a VLM/LLM planner via memory-injected reranking — but the project's own ablations show the importance/affordance/recency/audio-DOA heads are inert-or-redundant, so this is hard to sell as a WIN; (2) the audio->LTM WRITE (lifelong: hear an anomaly at a non-line-of-sight location, persist it, recall on a later visit) — this IS a real conceptual gap not covered by HomeEmergency/SAVN/AVLMaps, but it is currently only an oracle-source upper bound and unproven. Honest verdict: the system-integration is real but the audio contribution as framed is at best incremental and at worst already-done; the paper needs a sharper, audio-causally-necessary contribution to clear an ICRA novelty bar.

## Axis C — Instance discrimination, retrieval & open-vocab detection

**SOTA.** Open-vocabulary ObjectNav is crowded and fast-moving. The dominant modular recipe (VLFM, ICRA 2024) combines frontier exploration with a VLM image-text cosine value map (BLIP-2/CLIP) for the goal, plus an open-vocab detector for the stop decision. The community has converged on OWLv2 for indoor open-vocab nav (HM3D-OVON, IROS 2024, found OWLv2 beats GroundingDINO), with a standard 1.0m success radius. Memory/lifelong navigation is its own line: GOAT-Bench (CVPR 2024) is the canonical multi-modal lifelong benchmark and already studies whether explicit/implicit scene memory helps across long multi-goal episodes; ConceptGraphs (ICRA 2024) and HOV-SG (RSS 2024) are SOTA for open-vocab, instance-grounded, hierarchical 3D-scene-graph memory. On the bottleneck itself, it is now an established peer-reviewed result that CLIP-family embeddings carry fine-grained/instance information but the cosine readout discards it (Is CLIP the main roadblock, 2024), and that even DINOv2 needs region/MLP adaptation for instance ReID. The field's two answers to instance ambiguity are active get-closer-to-verify perception (IEVE, CVPR 2024) and geometric instance association into per-object scene-graph nodes (ConceptGraphs), rather than a better static caption embedding.

**How this project relates.** The project sits inside the modular VLM-cosine ObjectNav family and shares VLFM's exact core mechanism (goal-vs-observation cosine), but stores it as a persistent SBERT-caption-text index (inherited from ReMEmbR) rather than a spatial value/feature map. Its distinctive moves are a bio-inspired consolidation/importance pipeline (I=aR+bU+gN), memory-INJECTED waypoint candidates (not just reranking), and the audio-anomaly framing, none of which appear in VLFM/HM3D-OVON/GOAT-Bench. Where it differs sharply from the SOTA memory work (ConceptGraphs/HOV-SG): those build true instance-grounded, geometrically-associated, hierarchical scene graphs, whereas the project's memory is a FLAT caption-cosine index (its own audit notes mid layer empty, coarse inert, retrieval queries fine-only), so the 3-layer hierarchical LTM claim is weaker than the named hierarchical baselines and must not be over-claimed. The bottleneck the project measured is a known, citable CLIP limitation. The localization-bound 0.1m finding is real but partly self-inflicted: the field uses 1.0m (HM3D-OVON, GOAT-Bench), where the project's own warm SR is a healthy 0.667. Net: a legitimate variant in a well-populated space, with a credible empirical thesis (memory helps on relevant revisits) but a memory architecture behind the geometric-scene-graph SOTA on the very axis (instance discrimination) it identifies as its bottleneck.

**Novelty.** Mixed, and honesty matters. (1) Memory helps on warm revisits is well-reproduced internally but NOT a novel question: GOAT-Bench already benchmarks whether scene memory helps in lifelong multi-goal Habitat navigation, and ConceptGraphs/HOV-SG already demonstrate reusable open-vocab memory for repeated nav. The contribution must be framed as a specific mechanism (consolidation + memory-injected waypoints + the audio trigger) plus diagnostic/negative findings, not as we showed memory helps. (2) The instance-discrimination bottleneck is genuinely well-characterized by the project (a clean quantified diagnosis: 0.628 vs 0.535 separable, query collapses to 0.047) and aligns with but does not advance beyond the 2024 CLIP-roadblock paper; as a measurement on embodied caption-retrieval memory it is a nice confirmation, not a new method. (3) The genuinely new angle is the audio-anomaly-response framing, but the project itself proved audio is currently a code-level NO-OP for retrieval, so the novel part is unrealized; the paper's novelty stands or falls on the non-LOS, non-oracle audio-to-LTM write actually beating vision-only. (4) The exhaustive negative results (every importance/affordance/recency/audio-DOA head is inert-or-redundant because of the instance bottleneck) are a credible, unusual contribution IF framed as a rigorous why-heads-do-not-help-in-instance-ambiguous-single-goal-eval study. Verdict: incremental-to-borderline as a method paper; the strongest honest framing is a diagnostic/negative-results plus one-new-mechanism (audio) paper, not a new SOTA memory architecture paper.

The better-embedding plan is right in spirit but under-powered: the cheapest correct first step (per the CLIP-roadblock paper) is query construction/latent re-projection, NOT a detector, which matches the project's own $0 finding that a detector is unjustified.
- Detector negative may be discounted: OWLv2 noise floor on Habitat sim renders matches the known real-to-sim domain gap for open-vocab detectors, but reviewers may attribute it to using simulation. Cite the sim2real open-vocab-detection domain-gap evidence explicitly so the negative reads as expected, not a setup flaw.
- 0.1m vs 1.0m framing: leading with localization-bound 0.1m binary SPL invites criticism of a non-standard radius. The standard 1.0m (HM3D-OVON, GOAT-Bench) is where the project's SR is strong (0.667 warm). Lead with 1.0m, present 0.1m as a diagnostic only.
- Audio novelty unrealized: the project proved audio is a retrieval NO-OP (anomaly==goal) and the audio-to-LTM write uses an ORACLE source position. For an ICRA audio paper this is the central risk: audio is dressing unless the non-LOS, DOA-derived (non-oracle) write is built and shown to beat vision-only. Without it, the one genuinely-new contribution is not demonstrated.
- Cross-environment transfer is structurally absent (waypoint injector is scene-filtered). Fine to state, but it removes lifelong cross-environment reuse from the claims, which is what a robotics reviewer most wants from a lifelong-memory paper. Be explicit that the result is within-scene same-category recall to avoid an over-claim rejection.

## Axis D — Evaluation protocols, benchmarks & venue expectations

**SOTA.** For embodied navigation eval, the field's settled conventions (Habitat ObjectNav Challenge 2022/2023) are: 1.0 m success radius + oracle object-viewability, SR and SPL as primary metrics, soft-SPL for partial progress, on HM3D-Semantics with 6 goal categories. Strong zero-shot ObjectNav systems now report ~46-54% SR / 25-31% SPL on HM3D (VLFM, GAMap, history-augmented VLMs, TopoNav, FOM-Nav). The lifelong/multi-goal regime — where memory is supposed to pay off — is owned by GOAT-Bench (CVPR 2024): GO-to-AnyThing with 5-10 sequential open-vocab goals per episode, 360 val episodes / 36 scenes, and an explicit memory-vs-memoryless analysis showing roughly 2x SPL degradation without memory. Notably, GOAT-Bench and most ObjectNav papers report single point estimates with no CIs or seeds; the statistical-rigor frontier (rliable, NeurIPS 2021; paired-bootstrap protocols) is rarely applied to these benchmarks. On the audio side, the established tasks are AudioGoal and Semantic Audio-Visual Navigation (SAVi, CVPR 2021) on SoundSpaces — navigate to a sounding/semantically-grounded object, with SR/SPL/SNA at 1.0 m, and 'heard/unheard' + 'static/dynamic' generalization splits. A 2026 concurrent work (Habitat-Echo / Sound-Triggered Mobile Manipulation, STMM-1.9K) does sim-only sound-triggered embodied response with binaural RIRs and real anomaly-like sounds — directly adjacent to this project's ICRA-2027 framing. Sim-only navigation papers remain publishable at ICRA/CoRL/RSS, but reviewers increasingly expect at least a qualitative real-robot demo for any deployment claim, and the backbone here (ReMEmbR, ICRA 2025) already set that precedent with a 25-min Nova Carter demo while its quantitative eval was sim/VQA-only.

**How this project relates.** This project sits in the GOAT-Bench / SAVi lineage (lifelong, memory-centric, Habitat) but makes three deliberate eval deviations, each defensible if argued: (1) PRIMARY metric is paired warm-minus-cold soft-SPL rather than absolute SR/SPL — justified because binary SPL@0.1 m is localization-bound (memory recalls a viewing pose ~0.5-1.5 m off the object) — but the team correctly ALSO reports binary SR at the standard 1.0 m ring (warm S3 0.667 vs S1 0.333), which is the comparable-to-field number and should be foregrounded. (2) A CONTROLLED PAIRED REVISIT design (same scene/category warm vs cold, S1/S2/S3 decomposition with paired bootstrap + 90% CI + significance) that is statistically MORE rigorous than GOAT-Bench's aggregate point estimates and aligned with rliable's recommendations — a genuine methodological strength. (3) Sim-only with offline-rendered SoundSpaces RIRs convolved O(1) at runtime — standard practice, inherited from SoundSpaces/SAVi. The contribution is correctly framed as a MEMORY DELTA (the LTM's recall value), not an absolute-SOTA claim, which is the right and honest framing given the 2B/7B ReMEmbR backbone's exploration ceiling keeps absolute SR well below VLFM-class systems. Versus ReMEmbR itself, this is a real extension: ReMEmbR was never evaluated on closed-loop ObjectNav/SPL or with a memory ablation, so the controlled S1/S2/S3 ablation is new. Versus GOAT-Bench, the key difference is that GOAT compounds recall WITHIN a single multi-goal episode whereas this project's positive result is CROSS-VISIT (warm revisit) but WITHIN-scene and same-category — narrower than GOAT's open-vocab multi-goal regime, and cross-environment transfer is structurally absent (the team has verified this).

**Novelty.** The EVAL-DESIGN novelty is modest-but-real: a controlled paired warm/cold revisit ablation with S1/S2/S3 module decomposition and proper bootstrap CIs is more rigorous than the prevailing single-point-estimate norm (GOAT-Bench, most ObjectNav papers) and cleanly attributes the gain to the LTM. That rigor is a selling point, not a contribution per se. The TASK framing (acoustic-anomaly-triggered lifelong recall) is fresh relative to SAVi/AudioGoal (which are single-episode, not lifelong-cross-visit) — but it is at material risk from the concurrent Habitat-Echo/STMM work (sim-only sound-triggered embodied response in Habitat), so the team must carve out 'persistent cross-visit LTM' as the distinguishing axis. The honest weak spots the team has already self-diagnosed will read as such to reviewers: (a) the audio is currently a code-proven NO-OP for retrieval (anomaly_object == goal), so the headline +0.171/+0.24 is PURE VISUAL revisit recall with audio as dressing — until the non-LOS audio->LTM write makes audio load-bearing, the 'acoustic anomaly response' title overclaims; (b) the audio write uses the GT source xyz (oracle/privileged), an upper bound, not a perception result; (c) n is small (12-26), single-cell-fragile (leave-one-out straddles zero on some cells), within-scene, same-category — the effect is real and reproduced ~12x but each repro is largely the same arm re-analyzed, not independent datasets. Net: the memory-helps-when-relevant finding is genuine and well-supported; the ACOUSTIC-ANOMALY contribution is currently aspirational/oracle-bound and is the part most likely to be judged incremental-or-unfinished unless audio is made causally load-bearing with a non-oracle source signal.

**Key papers.**
- **GOAT-Bench: A Benchmark for Multi-Modal Lifelong Navigation** — CVPR 2024 (arXiv 2404.06609) — https://arxiv.org/abs/2404.06609  
  THE single most important comparator for this paper's eval design. It is the established Habitat lifelong/multi-goal navigation benchmark with an explicit memory-vs-memoryless analysis — exactly this project's thesis. Conventions reviewers will hold the paper to: 1.0 m success radius, SR + SPL as primary metrics, 360 val episodes / 36 scenes, open-vocab goals (category/language/image), 5-10 sequential subtasks/episode so within-episode recall can compound. Crucially GOAT's own memory ablation drops the map/hidden-state between subtasks and reports AGGREGATE point estimates (no CIs, no seeds) — so this project's paired-bootstrap + CI design is actually MORE rigorous than the field standard, a defensible strength. A reviewer WILL ask 'why not just run GOAT-Bench?'
- **ReMEmbR: Building and Reasoning Over Long-Horizon Spatio-Temporal Memory for Robot Navigation** — ICRA 2025 (arXiv 2409.13682) — https://arxiv.org/abs/2409.13682  
  The declared backbone. Critical positioning fact: ReMEmbR is evaluated ONLY as long-horizon video QA (NaVQA, 210 questions over 7 videos; spatial L2<15 m / temporal L1<2 min / descriptive accuracy), with a qualitative 25-min real-robot demo and NO SPL/ObjectNav and NO memory/no-memory ablation. So porting its retrieval-augmented memory into a closed-loop ObjectNav/SPL setting WITH a controlled memory ablation is a genuine methodological extension, not a re-run. The paper must state this precisely (it is the cleanest novelty hook) and must reproduce/cite ReMEmbR's own numbers as the upstream anchor.
- **From Instruction to Event: Sound-Triggered Mobile Manipulation (Habitat-Echo / STMM-1.9K)** — arXiv 2601.21667 (Apr 2026) — https://arxiv.org/abs/2601.21667  
  CONCURRENT DIRECT COMPETITOR and the highest-risk citation gap. It is sound-triggered embodied response in Habitat with spatial audio (binaural RIRs), real anomaly-like sounds (alarms, phones, doors, sinks), a 1.9K-episode dataset (660 train / 222 test single-event + 355 multi-event), sim-only on a 'Habitat-Echo' platform. It overlaps the ICRA-2027 framing heavily (sound onset -> ground source -> respond). The paper MUST cite it and articulate the difference: this project's contribution is the LIFELONG LTM + warm/cold recall, not the manipulation; STMM has no persistent cross-visit memory. If unaddressed, a reviewer flags the audio framing as scooped.
- **Semantic Audio-Visual Navigation (SAVi)** — CVPR 2021 (arXiv 2012.11583) — https://arxiv.org/abs/2012.11583  
  The canonical 'navigate to a semantically-meaningful sounding object, even after the sound stops, using persistent memory' task — 21 object-sound categories on Matterport3D/SoundSpaces, SR/SPL/SNA metrics. This project's audio task is a close cousin (anomaly sound co-located with a captioned object) and its 'memory after sound stops' motivation is nearly identical. Must cite and contrast: SAVi is single-episode within-scene; this project's pitch is cross-VISIT lifelong recall. Sets the metric expectations (SR/SPL/SNA at 1.0 m) reviewers will apply to the audio results.
- **SoundSpaces / SoundSpaces 2.0: Audio-Visual Navigation in 3D Environments** — ECCV 2020 / NeurIPS 2022 (arXiv 1912.11474) — https://arxiv.org/abs/1912.11474  
  The rendering substrate this project uses and the origin of the AudioGoal task + its SR/SPL/SNA evaluation conventions and 'heard vs unheard' / 'static vs dynamic' splits. Must cite as the audio engine and to justify offline-RIR-then-O(1)-convolution as standard practice. Reviewers familiar with SoundSpaces will expect the 'heard/unheard' generalization framing and will note this project tests within-scene only.
- **Deep Reinforcement Learning at the Edge of the Statistical Precipice (rliable)** — NeurIPS 2021 Outstanding Paper (arXiv 2108.13264) — https://arxiv.org/abs/2108.13264  
  The reference reviewers cite when they demand statistical rigor on small-n embodied results. Advocates stratified bootstrap CIs, interquartile mean, performance profiles over point estimates. This project's paired-bootstrap + 90% CI + permutation-style design is in the spirit of rliable and should be framed that way; but rliable's message (point estimates at small n are unreliable; aggregate across tasks) is exactly the lens that exposes the n=12-26, single-cell-fragile, leave-one-out-straddles-zero caveats the team already documented. Cite it proactively to pre-empt the rigor critique.
- **VLFM: Vision-Language Frontier Maps for Zero-Shot Semantic Navigation** — ICRA 2024 (arXiv 2312.03275) — https://arxiv.org/abs/2312.03275  
  The de-facto zero-shot ObjectNav-on-HM3D baseline (~52.5% SR / 30.4% SPL at 1.0 m). Establishes the absolute-performance bar reviewers carry in their heads. This project's frontier+memory stack is a relative of VLFM, so reviewers will expect either a VLFM-style frontier-only baseline (which the team HAS as setting S1/S2) or an explanation of why absolute SR is far below VLFM (the ReMEmbR 2B/7B backbone exploration ceiling). Must situate the contribution as a memory delta, not an absolute-SOTA claim.
- **TopoNav / FOM-Nav / MetaNav / TrajRAG (2025-2026 memory-augmented ObjectNav)** — arXiv 2509.01364 / 2512.01009 / 2605.01700 (2025-2026) — https://arxiv.org/abs/2509.01364  
  Cluster of very recent memory/experience-augmented navigation works (topological memory graphs, frontier-object maps, retrieval of historical trajectories) reporting SOTA SR/SPL on HM3D. TrajRAG in particular is retrieval-of-past-trajectories — conceptually adjacent to this project's retrieval-augmented LTM. These are the 'related memory-for-navigation' citations a reviewer expects in the related-work table; the paper must position its bio-inspired consolidation + 3-layer FAISS LTM against map-/graph-/trajectory-memory and explain what hierarchical consolidation adds.
- **Habitat ObjectNav Challenge 2022/2023 (rules, metrics, splits)** — AI Habitat (official challenge pages) — https://aihabitat.org/challenge/2023/  
  Authoritative source for the protocol reviewers treat as ground truth: 6 goal categories (chair/couch/plant/bed/toilet/tv), 1.0 m success radius + oracle-viewability, SPL defined to nearest instance, soft-SPL as the partial-progress metric, val/test split sizes (~1000 test episodes). The team's use of soft-SPL as PRIMARY (because binary SPL@0.1 m is localization-bound) deviates from the challenge's primary-SPL convention and must be justified explicitly against this reference, and binary SR must ALSO be reported at the standard 1.0 m ring (which the team does: warm S3 0.667 vs S1 0.333).

**Risks / gaps.**
- TITLE/CLAIM MISMATCH (highest risk): the paper is framed as 'LTM-grounded acoustic anomaly response' but audio is a code-proven no-op for retrieval (anomaly_object==goal) and the headline gain is pure visual revisit recall. A reviewer who reads the ablation will say the audio does no work. Either make audio causally load-bearing (onset-gate + non-LOS audio->LTM write that the visual pass did NOT map) and SHOW a sound-off vs sound-on contrast where sound-on wins, or retitle to a memory-revisit paper with audio as a triggering modality only.
- ORACLE-SOURCE AUDIO WRITE: writing the GT source xyz into the LTM is privileged information; reviewers will call this an oracle upper bound, not a result. Needs a DOA-derived (even coarse lateral-sign) source estimate to be a real perception claim, or must be labeled explicitly as an upper-bound analysis.
- SMALL-N / SINGLE-CELL FRAGILITY: n=12-26, within-scene, same-category, with leave-one-out straddling zero on some cells and '~12 reproductions' that are largely re-analyses of the same arm rather than independent datasets. rliable-style reviewers will discount point estimates; need more scenes/categories/seeds or honest performance profiles and a clear statement of effective independent n.
- NO CROSS-ENVIRONMENT TRANSFER: the waypoint injector hard-filters to the current scene, so the lifelong claim is within-scene revisit, not the cross-environment reuse a 'lifelong memory' title implies. Must scope the claim precisely; GOAT/lifelong reviewers expect unseen-scene generalization.
- NON-STANDARD PRIMARY METRIC: making soft-SPL primary deviates from the ObjectNav-challenge SPL/SR convention. Defensible (binary SPL@0.1 m is localization-bound) but must be argued explicitly AND accompanied by standard SR/SPL@1.0 m as the comparable headline (the team has these — foreground them).
- BACKBONE-CEILING / ABSOLUTE PERFORMANCE: absolute SR is far below VLFM-class systems because the 2B/7B ReMEmbR exploration ceiling starves the episodes; reviewers may question whether the memory delta would survive on a stronger explorer. Pre-empt by stating the delta is backbone-relative and arguing the mechanism is planner-independent (memory injection).
- SIM-ONLY: acceptable at ICRA/CoRL for a method paper, especially with SoundSpaces precedent, but the ICRA robotics audience will expect at least a qualitative real-robot or real-audio demo (ReMEmbR set this bar with its Nova Carter demo). Absence of any real-world component weakens the 'robot' framing for an ICRA submission specifically.
- MISSING EXTERNAL MEMORY BASELINE: the ablation is entirely self-referential (S1/S2/S3 of one stack). Reviewers may want at least one external memory-for-navigation comparator (map-memory or trajectory-retrieval) to show the bio-inspired hierarchical LTM beats a simpler memory, not just no-memory.
